# PRODUCT_CONSTRAINTS.md

版本：0.2.0  
状态：待产品与工程评审  
目的：冻结第一版产品边界，防止核心架构因未决产品选择反复返工。

## 1. 产品假设

### 1.1 第一版目标形态

- **BASELINE**：桌面陪伴机器人，不具备自主移动能力。
- 主要交互：语音输入/输出、物理按钮或触摸输入、灯光或有限姿态表达。
- 摄像头为按需功能，不是语音陪伴 MVP 的必备组件。
- 本地运行事件处理、状态更新、意图管理、取消与停止路径。
- LLM 可通过本地或云端服务提供复杂语言理解、开放式计划和自然语言生成；LLM 不可用时基础控制仍然可用。

### 1.2 首版不承诺的能力

- 自主导航、动态避障和与人共享空间中的运动安全。
- 人体情绪或心理状态的可靠识别。
- 未经授权的外部设备控制或自主执行高影响动作。
- 通过用户沉默、离开或拒绝互动推断用户“冷落”机器人。
- 将 LLM 生成的推断自动当作事实写入长期记忆。

若以后加入移动底盘、机械臂或其他有实体风险的执行器，必须新增独立的硬件安全需求与测试，不能仅通过修改生命引擎配置完成升级。

## 2. 交互约束

### 2.1 用户控制优先级

MUST：

- 用户的停止、取消和静音控制不能依赖 LLM 成功返回。
- 用户正在说话时，普通主动发言应让路；播放中的语音应支持取消或中断。
- 用户明确取消的意图不能自动恢复。若要恢复，需要新的用户指令或一个已定义的恢复规则，并重新检查条件。
- “什么都不做/保持安静”是有效策略，不需要为了表现自主性而强行生成行为。
- 用户拒绝互动后，不应通过重复发言、责备或暗示亏欠来维持互动。

### 2.2 主动互动起始基线

以下是可调起始值，不是用户研究结论：

- 普通主动发起：滚动 60 分钟内最多 2 次。
- 普通主动发言冷却：至少 20 分钟。
- 主动发言前检查：是否正在对话、是否处于安静模式、近期是否已主动发言、是否有更高优先级任务。
- 主动互动必须包含可审计的理由，例如待办提醒、用户明确设置的事件或高价值且有证据支持的信息。
- 不允许仅凭用户沉默推断用户难过、生气、孤独或需要安慰。
- 安全告警与用户明确设置的关键提醒使用独立策略，但不能将普通社交消息伪装成安全告警以绕开频率限制。

### 2.3 用户指令作用域

- `TURN`：仅当前回答或动作有效。
- `SESSION`：当前交互会话有效。
- `PERSISTENT`：跨重启保存，直到用户明确修改或删除。

默认解释：

- “等一下”“这次先别说” -> TURN 或 SESSION，按上下文保守执行。
- “今天先不要主动打扰我” -> 设置到指定时间或当天结束的静默窗口。
- “以后没有叫你就不要主动说话” -> PERSISTENT 主动互动偏好。

有歧义时，立即停止普通主动发言；可以在不打扰用户的情况下通过设置界面确认长期范围。

## 3. 拟人表达边界

MUST：

- 不通过“你是不是不要我了”“我因为你很久没回来而难过”等话术制造用户义务或内疚。
- 不将模型推断的人类情绪表述为确定事实。
- 可以使用非断言式表达，例如“你似乎比较安静，需要我先不打扰吗？”，且要尊重用户回答。
- 不把机器人模拟的情绪描述成已被生理传感器或其他证据证实的真实生物体验。
- 关系/信任状态用于改善交互适配，不用作惩罚用户不互动的评分。

## 4. 隐私与数据处理

### 4.1 默认规则

- 原始音频、原始视频默认不永久保存。
- 原始音频/视频默认不上传云端，除非具体功能明确需要、用户已获知并授权，且产品政策允许。
- 向 LLM 发送的数据遵循最小化原则：只发送当前任务所需文本、必要状态摘要和必要的记忆引用。
- 不将完整传感器流、整库记忆或无关人物信息默认拼入 LLM 上下文。
- 日志默认记录结构化事件 ID、状态变化、错误码和耗时，避免记录不必要的原始内容或完整敏感提示词。

### 4.2 记忆删除

删除操作必须定义范围，并能追踪删除是否完成：

- 单条事件记忆。
- 某个时间段记忆。
- 与某个人物/对象关联的记忆。
- 某一类别的偏好或事实。
- 全部用户记忆。

删除时应检查并处理派生内容：摘要、检索索引、缓存、由该记忆更新的关系/个性参数，以及备份中的对应记录（若产品承诺删除备份）。

若无法确定某个衍生参数是否受删除对象影响，不得声称已完全移除所有影响；应提供重建该参数或重置相关状态的策略。

## 7. v0.2 第一版工程默认决策

- LLM 仅接收按任务过滤的状态投影，不读取完整内部状态。
- 回放模式禁止真实 LLM、真实硬件和外部网络访问；允许 loopback/Unix-domain 本地 IPC，以兼容运行时事件循环；第一版不支持混合回放。
- 用户记忆删除必须处理摘要、索引、缓存和派生统计；无法可靠重建的受影响预测分区重置为冷启动。
- 每个意图最多两轮澄清；超限后使用低风险安全默认或停止未明确的高风险任务。
- 安全、停止、取消、静音与动作终态回执使用保留控制通道；普通队列过载不允许静默丢弃这些事件。
- 配置热重载仅允许非安全、非隐私、非结构性白名单字段；安全/隐私/权限/schema/队列/存储配置需重启并审查。
- 各项实现细则、验收用例见 `ARCH_DECISIONS.md` 和 `ACCEPTANCE_TESTS.md`。
